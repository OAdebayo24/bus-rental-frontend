## BUS RENTAL - Bus Leasing and Hiring Platform

A comprehensive React application, for a leasing and vehicle hiring platform built with modern technologies and seamless integration. Users can compare, book and search buses instantly, while companies can list and manage their fleet, track bookings, and analyze revenue.

## Tech Stack

- **Frameworks**: ReactJS
- **Routing**: React Router 
- **Authentication**: JWT with passport
- **State management**: Zustand toolkit
- **API communication**: Axios 
- **User Interface Styling**: TailwindCSS
